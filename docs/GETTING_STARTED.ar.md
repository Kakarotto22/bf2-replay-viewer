# البدء السريع

English: [GETTING_STARTED.md](GETTING_STARTED.md). كل ما يطبعه المحلّل ويصدّره: [USAGE.ar.md](USAGE.ar.md).

## 0. ما تحتاجه

| | يلزم لـ |
|---|---|
| Python 3.10 أو أحدث | كل شيء |
| تسجيلات `.bf2demo` | كل شيء (القسم 1) |
| Flask وPillow (`pip install -e ".[web]"`) | العارض في المتصفح (المحلّل في الطرفية لا يحتاج شيئاً) |
| **نسختك الخاصة من Battlefield 2** | أيقونات اللعبة وخطوطها وخرائطها المصغّرة في العارض (اختياري، القسم 2) |

```bash
git clone https://github.com/Kakarotto22/bf2-replay-viewer.git
cd bf2-replay-viewer
python -m venv .venv && . .venv/bin/activate          # في ويندوز: .venv\Scripts\activate
pip install -e ".[web]"
```

## 1. الحصول على تسجيلات

* **على خادمك:** ضع `sv.autoRecord 1` في إعدادات الخادم (ملف `.bf2demo` لكل خريطة ويُكتب عند نهاية الجولة)، أو ابدأ وأوقف يدوياً من وحدة التحكم:
  `demo.recordDemo <اسم>` ثم `demo.stopRecording` (يفشل بصمت إن كان اسم الملف موجوداً).
* **ملفات موجودة:** أي ملف `.bf2demo` لديك، مثلاً من مشغّل خادم يشارك تسجيلات جولاته.
* لا تنشر تسجيلات مباريات الآخرين: فيها أسماء لاعبين (انظر [NOTICE.md](../NOTICE.md)).

## 2. جلب أصول اللعبة (الأيقونات والخطوط والخرائط)

العارض لا يضمّ ملفات EA أبداً. هو **يبني مخزناً صغيراً خاصاً من نسختك المثبّتة** عند أول حاجة.

1. ثبّت Battlefield 2 (أي تثبيت عادي، ويعمل أيضاً تحت Wine / Proton). يبحث العارض في
   `C:\Program Files (x86)\EA Games\Battlefield 2` وفي `C:\Program Files\EA Games\Battlefield 2` وفي المجلد المحدَّد بمتغير البيئة
   `BF2_GAME_ROOT` (المجلد الذي يحتوي `mods/bf2/Levels`):

   ```bash
   export BF2_GAME_ROOT="/path/to/Battlefield 2"        # في PowerShell:  $env:BF2_GAME_ROOT = "D:\Games\Battlefield 2"
   ```
2. ابنِ المخزن مرة واحدة (اختياري، ويحدث تلقائياً عند أول استخدام):

   ```bash
   bf2view --build-assets
   ```

   يقرأ `Menu_client.zip` و`Fonts_client.zip` وقوالب الكائنات وملف `Localization/English/english.utxt`، ويكتب فقط ما ترسمه الصفحة (نحو 0.3 ميغابايت
   من الأيقونات والخطوط، مع خريطة كل مرحلة تفتحها) في `~/.bf2demo-viewer-cache/game/`. بعدها لا يحتاج مجلد اللعبة. غيّر المكان بـ `--cache DIR`.
3. **لا تنشر مجلد التخزين هذا ولا ترفعه إلى git** (فيه رسومات EA). الخادم العام يجب أن يعمل بدون اللعبة.

بلا نسخة من اللعبة؟ يعمل العارض أيضاً: شبكة بحسب مواقع التسجيل، وأشكال بسيطة بدل الأيقونات، وخطوط النظام.

### خرائط أوضح (اختياري)

الخريطة المصغّرة في اللعبة 512 بكسل. توجد حزم مجتمع بتفاصيل أعلى، مثل *High Definition Minimap* على ModDB (8192 بكسل). نزّلها من صاحبها (لا نعيد نشرها هنا) ثم:

```bash
python scripts/import_hd_maps.py path/to/HighDefinitionMinimap.zip     # يحوّلها إلى JPEG بحجم 4096 داخل <cache>/hd_maps/
```

أو ضع صورك `<level>.jpg` في مجلد ومرّره بـ `--maps FOLDER`. على الهاتف لا تُحمَّل الخريطة المفصّلة إلا إذا فعّلتَ *خيارات أكثر > خريطة مفصّلة*.

## 3. الاستخدام

**الطرفية** (التفاصيل في [USAGE.ar.md](USAGE.ar.md)):

```bash
bf2demo round.bf2demo                       # التقرير المقروء كاملاً
bf2demo round.bf2demo --feed                # سجل القتل والانضمام والاستيلاء بالترتيب
bf2demo round.bf2demo --scoreboard          # من سجّل كم
bf2demo round.bf2demo --export-json out.json
bf2demo round.bf2demo --clip out.bf2demo --clip-start 120 --clip-end 180    # اقتطاع مشهد لفتحه في اللعبة
```

**المتصفح:**

```bash
bf2view --demos recordings --port 8080      # يمكن تكرار --demos، والبحث يشمل المجلدات الفرعية
```

افتح <http://127.0.0.1:8080/>. يُحلَّل التسجيل مرة واحدة في الخلفية (ثوانٍ للقصير ونحو 3 دقائق لجولة ساعتين بـ 79 لاعباً) ثم يُخزَّن، فالزيارة التالية فورية.
الاختصارات: **Space** تشغيل / إيقاف، **← →** تقديم وتأخير (مع Shift = 60 ثانية)، **+ / -** السرعة، **F** تتبّع اللاعب المحدد، **Tab** لوحة النتائج.
روابط مباشرة: `#/demo/<id>?t=<ثوانٍ>&p=<رقم اللاعب>&z=<تكبير>`.

**الهاتف:** افتح عنوان جهازك أو خادمك؛ يتغير التخطيط تلقائياً تحت 800 بكسل: الخريطة فوق واللوحات تحتها، وتكبير بإصبعين، ولمسة على الوحدة تُظهر اسمها.

## 4. النشر على الإنترنت

انظر [deploy/README.md](../deploy/README.md): systemd مع Caddy أو nginx على لينكس، وكلمة مرور للنسخة التجريبية، وإعدادات `BF2VIEW_*` (الرفع مغلق افتراضياً)،
وزر الدعم (`BF2VIEW_DONATE_TELEGRAM`). انشر **بدون** رسومات اللعبة ما لم تكن متأكداً من حقك في عرضها.

## 5. حل المشكلات

| العَرَض | الحل |
|---|---|
| تظهر نسخة قديمة من الصفحة | تحديث قسري (Ctrl+F5)؛ العارض يتحقق من ملفاته لكن وسيطاً قد يخزّنها |
| شبكة بدل الخريطة | لا توجد نسخة من اللعبة: اضبط `BF2_GAME_ROOT` ثم `bf2view --build-assets` |
| خريطة مخصّصة تظهر شبكة | متوقع: المراحل المخصّصة بلا خريطة مصغّرة أصلية؛ مرّر لـ `--maps` صورة باسم `<level>.jpg` |
| أول فتح لجولة طويلة بطيء | تُحلَّل مرة واحدة؛ انتظر أو افتحها لاحقاً |
| المنفذ مستخدم | `--port 8081`؛ وأوقف الخادم القديم أولاً (يحتفظ بالكود القديم في الذاكرة) |
| البدء من جديد | احذف `~/.bf2demo-viewer-cache` |
